# 🚀 SuperiorOS Maintainer Search

Hello everyone! 👋  

We are currently in search of **dedicated maintainers** for **SuperiorOS (Android 16)**.  
SuperiorOS is a clean, stable, and performance-oriented custom ROM built to deliver the best Android experience possible.

---

## 🧩 Requirements

To ensure the quality and consistency of SuperiorOS, we have a few prerequisites for all potential maintainers:

1. **Knowledge of Git**  
   You should be proficient in essential Git operations such as `push`, `pull`, `cherry-pick`, and `rebase`.  
   This ensures smooth collaboration and proper source management.

2. **Thoughtful Feature Requests**  
   We value creativity and new ideas — but please keep feature requests practical and meaningful.  
   Unnecessary or spammy requests won’t be entertained.

3. **Proper Commit Authorship**  
   Always maintain accurate commit authorship.  
   This helps us keep track of contributions and ensures proper credit.

4. **Preserve Source Integrity**  
   All maintainers are expected to preserve the official SuperiorOS source for official releases.  
   Any local modifications should align with our project’s standards and goals.
